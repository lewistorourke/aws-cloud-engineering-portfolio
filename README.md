# AWS Cloud Engineering Portfolio

Welcome to my AWS Cloud Engineering Portfolio. This repository contains a collection of hands-on AWS projects completed while studying the AWS Certified Solutions Architect – Associate curriculum.

The purpose of this portfolio is to demonstrate practical experience designing, deploying, securing, and managing cloud infrastructure using Amazon Web Services (AWS).

---

## About This Portfolio

This portfolio focuses exclusively on practical, hands-on projects rather than theory notes. Each project includes:

- A project overview
- AWS services used
- Practical tasks completed
- Security concepts demonstrated
- Key lessons learned
- Screenshots
- Skills demonstrated

The projects showcase core cloud engineering concepts including identity and access management, compute, networking, load balancing, databases, DNS, storage, content delivery, and monitoring.
